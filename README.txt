=======================================================
  पेंशन कैलकुलेटर - Progressive Web App (PWA)
=======================================================

यह फोल्डर PWA के रूप में तैयार है।

Android पर ऐप की तरह इंस्टॉल कैसे करें:

1. इन सारी फाइलों को किसी वेब होस्टिंग पर अपलोड करें 
   (जैसे GitHub Pages, Netlify, Vercel, या अपना सर्वर)
   - index.html
   - manifest.json
   - sw.js
   - icon-192.png
   - icon-512.png

2. Android फोन पर Chrome ब्राउज़र से उस लिंक को खोलें।

3. Chrome मेनू (तीन बिंदु) → "Add to Home screen" या "Install app" चुनें।

4. होम स्क्रीन पर ऐप आइकॉन आ जाएगा। अब यह ऑफलाइन भी काम करेगा।

पासवर्ड: satyamani@hc

नोट: लोकल फाइल (file://) से PWA इंस्टॉल नहीं होता। 
      इसे किसी https वेबसाइट पर होस्ट करना जरूरी है।
